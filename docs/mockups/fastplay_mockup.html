Fast Play — ranked by relative signal only

Fast Play games are Maine's quick-pick terminal tickets — a different family from the scratch cards in Best pick today. The state publishes each game's percent unsold and total unclaimed dollars, but not its print run or overall odds, so expected value can't be computed here yet and no Fast Play game carries a grade. Every game below is ordered only by its relative unclaimed-money signal — how its unclaimed total compares to other Fast Play games today. That's a comparison, never a probability, and it does not predict where a winning ticket sits.

Caution: as with the scratch pipeline, "unclaimed" dollars are an upper bound. Some of that money sits on tickets already sold but not yet redeemed rather than tickets still on terminals — so both the raw totals below and the relative signal built from them can overstate what's actually left to win.

Ranked by relative signal

Bar length is each game's unclaimed-dollar signal relative to the highest game in this list today — not a score, not a percentage of anything, and not an EV.

Progressive jackpot games — not rateable

These games' top prize is an uncapped jackpot. Its current dollar value isn't published anywhere scrapable, so it's excluded from ranking and can never get an expected value in this view — permanently, not just until more data arrives.
